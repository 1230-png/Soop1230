🌙 감성힙합 자동화 스튜디오 - 설치 방법
==========================================

Windows 사용자를 위한 최간단 설치 가이드:

**1단계: 폴더 준비**
   - 다운로드한 폴더를 원하는 위치에 저장하세요
   - 예: C:\Users\사용자명\Documents\감성힙합스튜디오\

**2단계: Python 설치 확인**
   - Python이 설치되어 있는지 확인하세요
   - 설치되지 않았다면 python.org에서 다운로드 후 설치

**3단계: 단축키 생성 (권장)**
   - "setup_shortcut.bat" 파일을 더블클릭하세요
   - 바탕화면에 "감성힙합 스튜디오" 아이콘이 생성됩니다
   - 이제 이 아이콘을 클릭하면 앱이 자동으로 실행됩니다!

**또는 직접 실행:**
   - "launcher.pyw" 파일을 더블클릭하면 앱이 바로 실행됩니다

🆘 트러블슈팅:

Q: 단축키가 생성되지 않는다면?
A: 관리자 권한으로 setup_shortcut.bat을 실행해보세요
   (마우스 우클릭 → 관리자 권한으로 실행)

Q: Python이 없다면?
A: python.org에서 Python 3.8 이상 설치
   설치할 때 "Add Python to PATH" 체크 필수!

Q: 앱이 실행되지 않는다면?
A: run.bat 파일을 실행하면 설치 과정을 볼 수 있습니다
   (오류 메시지를 참고하세요)
