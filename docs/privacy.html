개인정보처리방침

최종 수정일: 2026년 9월 3일 · 홈으로

1. 개요

이 도구는 운영자 본인의 YouTube 채널 @200-y3b에 영어 학습 영상을 자동으로 올리기 위한 개인용 프로그램입니다. 운영자 외의 이용자를 받지 않으며, 방문자로부터 어떠한 개인정보도 수집하지 않습니다.

2. 사용하는 권한

이 도구는 Google 계정 권한 중 다음 한 가지만 요청합니다.

  • https://www.googleapis.com/auth/youtube — 운영자 본인 채널에 영상을 업로드하고, 제목·설명·썸네일을 설정하며, 재생목록에 영상을 추가하기 위해 사용합니다.

이 권한은 위 목적 외에는 사용되지 않습니다. 영상 시청 기록, 구독 목록, 댓글 등 다른 정보를 읽거나 수정하지 않습니다.

3. 저장하는 정보

Google 인증 정보(클라이언트 ID·보안 비밀번호·갱신 토큰)는 GitHub의 암호화된 저장소 시크릿에만 보관되며, 코드나 공개된 위치에 저장하지 않습니다. 이 정보는 업로드를 실행하는 시점에만 사용됩니다.

이 밖에 저장하는 것은 어떤 표현을 이미 영상으로 만들었는지 기록한 목록뿐이며, 여기에는 개인정보가 포함되지 않습니다.

4. 제3자 제공

수집하는 개인정보가 없으므로 제3자에게 제공하는 정보도 없습니다. 영상 업로드를 위해 YouTube Data API를 사용하며, 이 과정은 Google 개인정보처리방침과 YouTube 서비스 약관을 따릅니다.

5. 권한 철회

운영자는 Google 계정 권한 관리 페이지에서 언제든 이 도구의 접근 권한을 취소할 수 있습니다. 취소하면 이후의 모든 업로드가 즉시 중단됩니다.

Privacy Policy (English summary)

This is a personal automation tool that publishes English-learning videos to its operator's own YouTube channel, @200-y3b. It has no other users and collects no personal information from anyone.

It requests a single Google permission, https://www.googleapis.com/auth/youtube, used solely to upload videos to the operator's own channel, set their title, description and thumbnail, and add them to playlists. It does not read or modify watch history, subscriptions, or comments.

OAuth credentials are stored only as encrypted GitHub repository secrets, never in code or any public location, and are used only at upload time. The only other stored data is a list of which phrases have already been turned into videos, which contains no personal information. No data is shared with third parties. Uploading goes through the YouTube Data API and follows the Google Privacy Policy and YouTube Terms of Service. Access can be revoked at any time at Google account permissions.
