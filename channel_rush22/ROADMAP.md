# 5개월 자동화 수익 로드맵

> 목표: 노트북 한 대로, 손대지 않아도 돌아가는 구조를 만들어 5개월 안에 현재
> 수입의 5배를 만든다.

이 문서는 위 목표를 그대로 받아 적은 계획이 아니라, **어디까지가 실제로 되고
어디부터가 안 되는지** 먼저 구분한 다음 짠 계획입니다.

---

## 0. 먼저, 틀린 전제 하나를 걷어냅니다

**"유튜브 자동 업로드 → 광고 수익 → 5배"는 5개월 안에 일어나지 않습니다.**

숫자로 보면 명확합니다.

| 조건 | 현실 |
|---|---|
| 쇼츠로 수익 창출 자격 | 구독자 1,000명 **+ 90일간 쇼츠 조회수 1,000만 회** |
| 한국 쇼츠 광고 RPM | 대략 1,000회당 100~300원 (롱폼의 1/10 수준) |
| 하루 2편 × 5개월 | 약 300편 |

300편으로 90일 안에 1,000만 조회를 만들려면 편당 평균 3만 회 이상이 꾸준히
나와야 합니다. 신규 채널이 자동 생성 콘텐츠로 그걸 안정적으로 내는 건 기대할
일이 아니라 운에 거는 일입니다. 설령 자격을 얻어도 쇼츠 RPM으로는 1,000만
조회가 **월 100~300만 원 수준**입니다.

그래서 이 로드맵은 광고 수익을 **주 수입원이 아니라 부산물**로 놓습니다.

### 대신 쓰는 구조

```
    자동 발행 (비용 0, 무한 반복)
            │
            ▼
      트래픽 / 노출
            │
    ┌───────┴────────┐
    ▼                ▼
 제휴·CPA 수익      디지털 상품
 (자격 조건 없음)   (한 번 만들고 계속 판매)
            │
            ▼
      광고 수익 (자격 갖춰지면 추가)
```

핵심은 **구독자 1,000명을 기다리지 않아도 되는 수익원부터 붙이는 것**입니다.
쿠팡 파트너스와 카드 발급 제휴는 구독자 0명에서도 오늘 시작됩니다.

## 1. 이미 만들어져 있는 것

오늘 기준으로 이 저장소에서 돌아가는 것들입니다.

| 자산 | 상태 |
|---|---|
| `channel_rush22/` 자동 발행 | 하루 2편, 완전 자동 |
| 콘텐츠 뱅크 60편 | 약 30일치 |
| `channel_200y3b/` | 하루 3편 + 주간 롱폼, 동작 중 |
| 렌더링·TTS·업로드 파이프라인 | 무료 스택, 검증 완료 |

**가장 중요한 건 마지막 줄입니다.** 채널 하나를 더 만드는 비용이
`content_bank.json` 한 개와 워크플로우 파일 한 개로 떨어졌습니다.
이 로드맵의 확장은 전부 여기에 기댑니다.

## 2. 월별 실행 계획

각 단계는 **한 번 세팅하면 이후 사람 손이 필요 없는 것**만 담았습니다.
사람이 반드시 해야 하는 일에는 🖐 표시를 했습니다.

---

### 1개월차 — 발행을 멈추지 않게 만들고, 측정을 켠다

이 달의 목표는 수익이 아니라 **끊기지 않는 발행과 데이터**입니다.

**해야 할 일**

1. 🖐 `RUSH_*` 시크릿 4개 등록 → 첫 수동 실행으로 업로드 확인
   (`SETUP.md` 3~4단계, 30분)
2. 🖐 워크플로우를 **기본 브랜치에 병합** — 안 하면 `cron`이 돌지 않습니다
3. 🖐 이 채널 전용 Google Cloud 프로젝트 분리 (API 할당량 충돌 예방)
4. 콘텐츠 뱅크를 60 → **180편**으로 확장 (하루 2편 × 3개월치)
5. 지표 수집 자동화 — `channel_food/scripts/collect_metrics.py`와
   `.github/workflows/channel_report.yml`이 이미 같은 일을 합니다. 이 채널용으로
   복제해 매일 조회수·시청 지속률·구독 전환을 CSV에 쌓으세요.

**이 달의 판단 기준**

30일 뒤 상위 10편과 하위 10편의 `topic`을 비교합니다. 여기서 나오는 답이
2개월차 전체를 결정합니다. **감이 아니라 이 CSV로 결정하세요.**

| 지표 | 30일 후 목표 |
|---|---|
| 발행 성공률 | 95% 이상 (실패 3회 이하) |
| 평균 조회수 | 편당 300회 이상 |
| 평균 시청 지속률 | 60% 이상 |

> 조회수가 편당 100회를 밑돈다면 문제는 발행량이 아니라 **hook**입니다.
> 채널을 늘리기 전에 hook 문구부터 다시 씁니다.

---

### 2개월차 — 수익 링크를 심는다 (여기서 첫 돈이 들어옵니다)

구독자 수와 무관하게 **오늘 시작 가능한** 수익원을 붙이는 달입니다.

1. 🖐 **쿠팡 파트너스 가입** (승인 1~3일)
   - `upload_video.py`의 설명란 생성부에 제휴 링크를 넣습니다
   - `content_bank.json` 항목별로 어울리는 상품을 매핑
     (예: `R056 총소유비용` → 블랙박스 / `R007 통장쪼개기` → 가계부)
   - 수수료는 3% 안팎이라 **이것만으로 큰돈은 안 됩니다.** 전환율을 측정하는
     연습용으로 쓰고, 진짜는 아래입니다.

2. 🖐 **금융 CPA 제휴 등록** ← 이 채널의 핵심 수익원
   - 카드 발급, 대출 비교, 앱 설치는 국내에서 **건당 만 원 단위**로 지급됩니다
   - 「머니러시」 주제와 광고 상품이 정확히 겹치는 게 이 니치를 고른 이유입니다
   - 제휴 마케팅 플랫폼(디비디비딥, 애드픽 등)에서 승인받고 링크를 발급
   - 월 10건 전환 = 월 10~30만 원. 조회수 수백만 회 없이도 나옵니다

3. **같은 콘텐츠를 블로그로 재활용** (완전 자동)
   - `content_bank.json`은 이미 제목·본문·태그를 갖고 있습니다
   - 티스토리/워드프레스 API로 하루 2건 자동 포스팅하는 워크플로우 추가
   - 검색 유입은 쇼츠와 달리 **시간이 지나도 계속 들어옵니다**
   - 애드센스 승인 조건이 유튜브보다 훨씬 낮습니다

**2개월차 예상 수익: 월 10~40만 원** (대부분 CPA)

### 3개월차 — 채널을 복제한다

1개월차 데이터로 "먹히는 주제"를 확인했으니 이제 복제합니다.
**우리가 만든 구조에서 이건 코드 작업이 아니라 JSON 작업입니다.**

1. **채널 2~3개 추가** — 각각 `content_bank.json` + 워크플로우 파일만 있으면 됩니다
   - 추천 니치: 생활법률 / 정부지원금 / 건강상식 — 전부 CPA 상품이 붙습니다
   - 🖐 채널 개설과 OAuth 발급만 사람이 합니다 (채널당 30분)
2. **교차 홍보 자동화** — 각 채널 설명란에 서로의 링크
3. 1개월차 데이터 기준으로 하위 20% 주제를 뱅크에서 제거

> ⚠️ **한 계정에 채널을 무한정 만들지 마세요.** 동일 콘텐츠를 그대로 복사해
> 여러 채널에 올리면 중복 콘텐츠로 제재를 받습니다. 채널마다 **주제와 문구가
> 실제로 달라야** 합니다. 우리 구조에서 이건 뱅크를 따로 쓰는 것으로 해결됩니다.

**3개월차 예상 수익: 월 30~80만 원**

---

### 4개월차 — 한 번 만들고 계속 파는 것을 붙인다

제휴는 남의 상품이라 마진이 정해져 있습니다. 이 달에는 마진이 100%인 걸 만듭니다.

1. **전자책 / 노션 템플릿**
   - 이미 쓴 180편이 초고입니다. 주제별로 묶으면 목차가 나옵니다
   - 예: "돈 새는 구멍 60가지 체크리스트"
   - 크몽·탈잉·자체 판매 페이지에 올리고 영상 설명란에 링크
   - 🖐 최초 편집 1회. 이후 판매는 전부 자동
2. **뉴스레터** — 수익원이 아니라 **내 소유 채널**입니다. 유튜브 계정이 정지돼도
   구독자 목록은 남습니다. 이게 이 로드맵에서 가장 저평가된 항목입니다
3. 1~3개월 데이터로 CPA 상품 교체 — 전환율 낮은 것부터 버립니다

**4개월차 예상 수익: 월 60~150만 원**

---

### 5개월차 — 사람 손을 뺀다

수익을 늘리는 달이 아니라 **유지보수를 없애는 달**입니다.

1. **실패 알림 자동화** — 워크플로우 실패 시 알림. 지금은 실패해도 아무도 모릅니다
2. **콘텐츠 뱅크 자동 보충** — 뱅크 잔량이 20편 아래로 떨어지면 이슈를 자동 생성
3. **월간 리포트 자동화** — 채널별 수익·조회수를 한 장으로
4. 성과 없는 채널 정리 — 3개월간 월 3만 원 미만이면 접습니다

**5개월차 예상 수익: 월 80~200만 원**

## 3. 그래서 5배가 되나?

**현재 수입이 얼마인지에 따라 다릅니다.** 이건 얼버무리는 게 아니라 이 계획의
가장 중요한 조건입니다.

| 현재 월 수입 | 5개월 후 5배 | 이 로드맵으로 |
|---|---|---|
| 20만 원 | 100만 원 | **가능성 높음** |
| 50만 원 | 250만 원 | 가능하지만 상위 결과 |
| 300만 원 | 1,500만 원 | **이 계획으로는 안 됩니다** |

정직하게 말하면, **직장 수입 300만 원의 5배를 5개월 만에 완전 자동으로**
만드는 방법은 없습니다. 있다고 하는 건 파는 사람 쪽입니다.

이 로드맵이 실제로 주는 건 다른 것입니다.

- **한계비용이 0인 자산**: 채널 하나 더 = JSON 하나 더. 사람 시간이 안 듭니다
- **복리로 쌓이는 구조**: 3개월 전에 올린 영상과 블로그 글이 지금도 벌어줍니다
- **수입원 분리**: 한 채널이 정지돼도 나머지가 돕니다

3년으로 늘려 잡으면 5배는 현실적인 목표가 됩니다. 5개월은 **구조를 완성하는
기간**이지 결실을 보는 기간이 아닙니다.

## 4. 이 계획이 실패하는 경우

미리 알고 있으면 대응할 수 있는 것들입니다.

| 위험 | 신호 | 대응 |
|---|---|---|
| 자동 생성 콘텐츠 저품질 판정 | 조회수가 편당 50회에 고정 | 뱅크 문구 전면 재작성. 채널 추가 중단 |
| 중복 콘텐츠 제재 | 채널 동시 경고 | 채널별 뱅크 완전 분리 |
| edge-tts 차단 | TTS 단계 403 | 오프라인 TTS(Piper)로 교체 |
| API 할당량 초과 | 업로드 403 quotaExceeded | 채널별 GCP 프로젝트 분리 |
| 금융 콘텐츠 정책 | 노란 딱지 | 상품 추천·수익 보장 표현 제거 |

가장 흔한 실패는 이 중 어느 것도 아니고 **2개월차에 수익 링크를 안 붙이고
계속 영상만 올리는 것**입니다. 발행은 자동이라 편하고, 제휴 등록은 사람이
해야 해서 미루게 됩니다. 그러면 5개월 뒤에도 수익은 0입니다.
