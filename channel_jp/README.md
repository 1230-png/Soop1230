# 귀트는 일본어 (channel_jp)

한국어 화자를 위한 **일본어 듣기 롱폼** 채널. 머니로직을 접은 자리를 쓴다.

## 왜 롱폼이고 왜 일본어인가

숏폼 시청 시간은 파트너 프로그램의 3,000시간에 **집계되지 않는다.** 머니로직은
28일에 조회수 8,414회를 받고도 시청 시간이 14.8시간이었다 — 99.5%가 숏폼이라
받은 트래픽이 세지지 않는 그릇에 담긴 것이다. 30분 영상을 40% 지속률로 보면
1회당 12분이 쌓이고, 3,000시간까지 필요한 조회수가 180만에서 1.5만으로 내려간다.
**형식이 주제보다 먼저다.**

일본어인 이유는 세 가지다. `longform/`(@200-y3b 영어)의 파이프라인이 그대로
재사용되고, 청중이 겹치지 않아 기존 채널을 깎지 않고, edge-tts 가 무료다.

## 왜 `longform/` 을 고쳐 쓰지 않았나

`longform/` 은 **가동 중이다.** 매일 @200-y3b 에 무인 발행한다. 거기에 언어
분기를 넣으면 일본어 쪽 실수가 영어 쪽 발행을 멈출 수 있다. 이 저장소는
디렉터리마다 독립이라는 규칙을 그래서 두고 있다(CLAUDE.md).

대신 코드가 겹친다. 그 값은 치르기로 한 것이다 — 겹친 코드는 한쪽이 깨져도
다른 쪽이 돌지만, 얽힌 코드는 같이 멈춘다.

## 문장 은행

```bash
python3 channel_jp/build_bank.py            # 검사하고 data/phrases.json 을 쓴다
python3 channel_jp/build_bank.py --check    # 검사만 (파일을 쓰지 않는다)
cd channel_jp && python3 -m pytest          # 검사기 자체의 테스트
```

`data/_parts/*.json` 이 원본이다. 주제별로 나눠 둔 이유는 300개를 한 파일에 두면
**사람이 검수를 못 하기 때문**이다. 파일 이름 순서가 곧 영상에서의 순서다.

`data/phrases.json` 은 **생성물이다.** 직접 고치지 말고 조각을 고쳐 다시 만든다.

### 검사기가 막는 것

머니로직은 제목에 `nan%` 가 박힌 영상을 여드레 동안 공개로 올렸다. 원인은
`float('nan') >= 0` 이 False 인 것이었지만, 진짜 문제는 **깨진 값이 발행까지
흘러간 것**이다. 그래서 이 검사는 영상 파이프라인 앞에 선다.

- 빈 칸 — 카드에서 빈 줄이 된다
- `ja`·`ex_ja` 에 한글 — TTS 가 일본어 음성으로 한글을 읽으려다 무음이 된다
- `yomi`·`ko` 에 가나·한자 — 카드에 그대로 찍히고 학습자는 한글인 줄 안다
- 같은 일본어 문장 중복 — 지우되 **몇 개가 사라졌는지 말한다**

마지막 항목이 조용하면, 150문장을 넣었는데 영상이 짧아진 이유를 찾을 수 없다.

초안 300개에서 이 검사가 실제로 세 건을 잡았다: `ja` 칸에 들어간 한국어 문장,
읽기 칸에 남은 `ん` 한 글자, 예문에 섞여 들어간 `three年`.

## 영상 만들기

```bash
python3 channel_jp/build.py --pack sleep_japanese --offline --limit 6   # 빠른 시험
python3 channel_jp/build.py --pack sleep_japanese --offline             # 길이까지 확인
python3 channel_jp/build.py --pack sleep_japanese                       # 진짜 (돈이 든다)
```

`--offline` 은 TTS 대신 무음을 넣는다. 네트워크도 API 키도 돈도 쓰지 않고
타이밍·카드·이어붙이기·인코딩을 전부 확인할 수 있다. `used.json` 도 건드리지
않는다 — 건드리면 다음 진짜 빌드에서 그 문장들이 이미 쓴 것으로 빠진다.

팩은 셋이다.

| 팩 | 길이 | 문장 | 언제 |
|---|---|---|---|
| `sleep_japanese` | 40분 | 150 | 금 |
| `situation_pack` | 14분 | 30 | 화 |
| `shadowing_drill` | 24분 | 45 | 목 |

`sleep_japanese` 가 주력이다. 사람들이 틀어 놓고 자기 때문에 1회당 시청
시간이 가장 길다.

## 목소리 — ElevenLabs

`ELEVENLABS_API_KEY` 환경변수로만 들어온다. **키가 없으면 멈춘다.** edge-tts
로 되돌아가지 않는다 — 되돌아가게 두면 어느 날 키가 만료됐을 때 목소리가
통째로 다른 영상이 조용히 올라간다. 채널 자격 증명에 대체 경로를 두지 않는
것과 같은 이유다.

음성 ID 는 `packs.yaml` 의 `voice_ja` · `voice_ja_alt` · `voice_ko` 에 있고
지금은 셋 다 같은 값이다. 다국어 모델(`eleven_multilingual_v2`)이라 한
목소리가 일본어와 한국어를 모두 읽는다. 나눌 일이 생기면 `voice_ko` 만
바꾸면 되고 코드는 안 건드려도 된다.

**느린 읽기에 값을 두 번 내지 않는다.** ElevenLabs 는 글자 수로 받는데,
같은 문장을 속도만 바꿔 두 번 보내면 값이 그대로 두 배다. 대신 보통 속도
음성을 받아 ffmpeg `atempo` 로 늦춘다. 음높이는 그대로고 글자 값은 한 번만
든다 — 수면 팩 한 편 기준으로 대략 4,400자가 3,300자로 내려간다.

한 편에 드는 글자 수(대략):

| 팩 | 글자 |
|---|---|
| `sleep_japanese` | 약 3,300 |
| `situation_pack` | 약 1,400 |
| `shadowing_drill` | 약 1,600 |

주 3편이면 한 달에 대략 25,000자다. 요금제를 고르기 전에 이 숫자를 볼 것.

## 카드

배경은 밝고, **진행 막대를 두지 않는다.** 화면 아래 가로 막대는 재생 바로
읽혀서 시청자가 영상이 멈춘 줄 알고 화면을 건드린다. 남은 분량은 오른쪽 위
`1 / 150` 이 이미 말해 준다.

순백을 쓰지 않는 이유는 자기 전에 트는 영상이기 때문이다. 어두운 방에서
화면만 하얗게 타오르면 눈이 아프다.

### 폰트

`lib/cards.py` 의 `find_font()` 는 **목록 순서로 고르지 않는다.** 후보마다
히라가나·가타카나·한자·한글을 실제로 그려 보고, 없는 글자가 하나라도 있으면
넘어간다.

이 검사가 없으면 조용히 깨진다. PIL 은 없는 글자를 만나도 예외를 내지 않고
.notdef(빈 칸이나 네모)를 그냥 그린다. 이 러너에서 실제로 확인한 것:

| 폰트 | 없는 문자 |
|---|---|
| NotoSansCJK | 없음 (쓸 수 있다) |
| fonts-japanese-gothic | 한글 |
| NanumGothic | 히라가나, 가타카나, 한자 |
| DejaVuSans | 전부 |

나눔고딕이 먼저 잡히면 일본어가 통째로 □ 로 나간다. 러너에는
`fonts-noto-cjk` 가 있어야 한다.

## 발행 차단

머니로직은 제목에 `nan%` 가 박힌 영상을 여드레 동안 공개로 올렸다. 원인은
`float('nan') >= 0` 이 False 라 항상 "하락"으로 갈라진 것이었지만, 진짜
문제는 깨진 값이 아무 저항 없이 발행까지 흘러간 것이다. 그래서 두 번 막는다.

**합성 전** (`verify_phrases`) — 고른 문장이 온전하지 않으면 edge-tts 든
ElevenLabs 든 한 번도 부르지 않고 멈춘다. 돈이 드는 단계 앞에 검사를 둔다는
CLAUDE.md 규칙과 같은 자리다.

**인코딩 후** (`verify_publishable`) — 하나라도 걸리면 0 이 아닌 코드로
끝난다. 파일은 남겨 둔다(무엇이 잘못됐는지 봐야 고치므로) 워크플로의 업로드
단계만 돌지 않는다.

- 제목·설명에 `nan` · `None` · `null` · 안 채워진 `{자리}`
- 영상에 들어간 문장이 0개
- 길이가 60초 미만
- `target_minutes` 에서 30% 넘게 벗어남 (`--limit` 실행은 제외)

경계를 `\b` 로 잡지 않는다. 파이썬의 `\b` 는 유니코드 기준이고 한글도 단어
문자라서 「문장 None개를 모았습니다」가 그냥 지나간다 — 깨진 값이 한국어
문장에 박힌 바로 그 모양인데. 좌우를 로마자만으로 막아서, 「난바(nanba)」
같은 멀쩡한 제목은 걸리지 않고 「None개」는 걸린다.

## 아직 없는 것

- **업로드.** `upload.py` 가 없다. 지금은 `build/<날짜>-<팩>/` 을 손으로
  올린다. `metadata.json` 의 `privacyStatus` 가 `private` 인 것은 일부러다 —
  머니로직이 무인 공개 발행으로 여드레 동안 깨진 영상을 냈다.
- **워크플로.** cron 을 걸기 전에 몇 편을 손으로 내 보고 정한다.

## 비밀값

**환경변수로만 다룬다. 코드·커밋·로그에 절대 넣지 않는다.**

- `ELEVENLABS_API_KEY` — 음성. 없으면 빌드가 멈춘다
- 유튜브 업로드용 `JPN_*` — 아직 발급하지 않았다

머니로직의 `MV_*` 와 공용 `YT_*` 는 쓰지 않는다 — 이유는 CLAUDE.md 에 있다.
