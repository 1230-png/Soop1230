# 🌙 감성힙합 자동화 스튜디오

AI 기반 완전 자동화 음악 제작 플랫폼

## ⚡ 빠른 시작

### Windows 사용자
1. 폴더에서 **`run.bat`** 파일 더블 클릭
2. 자동으로 패키지 설치 + 앱 실행
3. 브라우저에서 `http://localhost:8501` 접속

### Mac/Linux 사용자
```bash
pip install -r requirements.txt
streamlit run app.py
```

## ✨ 5가지 완벽하게 작동하는 기능

### 📋 1. 배치 설계
- 감정별 10곡 자동 생성
