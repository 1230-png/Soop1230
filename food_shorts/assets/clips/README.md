# 직접 촬영한 영상 넣는 곳

여기에 동영상을 넣으면 **인터넷에서 받은 영상보다 우선 사용됩니다.**

## 파일명

```
{콘텐츠 id}_title.mp4
{콘텐츠 id}_step1.mp4
{콘텐츠 id}_step2.mp4
{콘텐츠 id}_step3.mp4
```

`data/food_list.json` 의 `id` 를 씁니다. 확장자는 `.mp4` `.mov` `.webm` `.mkv`.

필요한 것만 넣어도 됩니다 — 없는 장면만 인터넷에서 받아옵니다.

## 규격

- 어떤 해상도·비율·길이여도 됩니다. 자동으로 1080×1920 세로로 채우고 잘라냅니다
- 2초 이상 권장 (짧으면 자동 반복됩니다)
- 720p 이상이면 화질이 좋습니다
- 자막이 아래쪽에 깔리므로 **조리 장면은 화면 위쪽~가운데**에 두면 좋습니다
