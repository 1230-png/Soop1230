## 📥 효과음 추가 방법

### 옵션 1: 직접 녹음하기

1. **스마트폰이나 컴퓨터로 요리 과정 녹음**
   - 음성은 제외하고 소리만 녹음
   - 각 동작마다 5-10초 정도 녹음

2. **mp3로 변환**
   ```bash
   ffmpeg -i input.wav -q:a 9 -n output.mp3
   ```

3. **폴더에 저장**
   ```
   /home/user/Soop1230/food_shorts/assets/sounds/
   ```

## ⚙️ 효과음 선택 방식

**generate_video.py**는 `food_list.json`의 `sound_type` 필드를 보고 자동으로 효과음을 선택합니다.

### 예시: food_list.json

```json
{
  "id": 1,
  "title": "집에서 만드는 마라탕",
  "sound_type": "불,국물",  // ← 이 타입에 맞는 효과음 선택
  "steps": [
    "야채 깎는 소리가 알싸한 마라탕",
    "끓는 육수가 맴맴~ 곧 완성",
    "입안에 톡 터지는 마라향"
  ]
}
```

**선택 방식:**
1. `sound_type`에 "불" 또는 "국물"을 포함한 파일을 찾음
2. 매칭되는 파일이 없으면 모든 파일 중에서 무작위로 선택
3. 최대 3개의 효과음을 합쳐서 5-10초 동영상에 넣음

## 💡 팁

1. **효과음 품질**
   - MP3, WAV, OGG 모두 지원
   - 비트레이트: 128kbps 이상 권장
   - 길이: 3-10초 정도가 적당

2. **효과음 균형**
   - 너무 크지 않게 (청취자 귀 보호)
   - 배경음 형식으로 5-10dB 정도 낮게

3. **다양성**
   - 같은 종류 효과음 3-5개씩 모아두기
   - 매 생성마다 다른 조합으로 섞임

## ❓ FAQ

**Q: 효과음은 어디에 저장해야 하나요?**
A: `/home/user/Soop1230/food_shorts/assets/sounds/` 폴더에 mp3 파일로 저장하세요.

**Q: 여러 효과음을 합칠 수 있나요?**
A: 네, generate_video.py가 자동으로 3개의 효과음을 선택해서 합칩니다.

**Q: 효과음이 없으면 어떻게 되나요?**
A: 침묵(5초)으로 자동 생성되므로 문제없습니다.

**Q: 효과음 파일 형식은?**
A: MP3, WAV, M4A, OGG 등 ffmpeg이 지원하는 모든 형식 가능합니다.

**Q: 어떤 효과음을 먼저 추가하면 좋을까요?**
A: 기름 튀기는 소리, 채소 깎는 소리, 물이 끓는 소리 3가지부터 추천합니다.
